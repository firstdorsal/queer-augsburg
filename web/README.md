# Queer Augsburg Web

## Quiz Feature

Jeopardy-style quiz board for events. Code-split and only loaded when accessed.

- `/quiz/control` - Host view for managing questions and awarding points
- `/quiz/board` - Display view for audience (open in separate window/projector)

State syncs across tabs via localStorage. Export/import game data as JSON.

## Orte und Online-Treffen

- Places are stored in their own collection. Editors pick a place from the dropdown in the
  meeting editor or create one there ("Neuen Ort anlegen" opens the map). The server copies
  name and coordinates into the meeting (`location`) and refuses meetings without a place,
  except online meetings.
- Online meetings ("Online-Treffen") have a platform and an optional link. A link is either
  public or, by default, members-only: then it is never part of the meeting list, the iCal
  feed or the local cache. Verified members (membership approved) and editors load it on
  demand from `GET /api/meeting_link/?m=<id>` ("Link anzeigen").
- API: `GET /api/places/`, `POST /api/create_place/` (both `UpdateMeetings`),
  `GET /api/meeting_link/`; see `/docs`. Types in `src/apiTypes` are generated by ts-rs
  (`cargo test` in `server/`).
- Logic and tests: `src/places.ts`, `server/src/place_rules.rs`; place names are compared
  with the same key in both (shared cases in `server/src/place_key_cases.json`).
- The migration of the old data is in `server/migrations/2026-10-21-places/`.
